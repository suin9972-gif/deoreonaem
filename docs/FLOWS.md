## F1 · 처음 쏟아내기 — "머릿속 좀 비우고 싶다"
> 구분: 첫 방문 · 상태: 기획 완료 · 담당 기능: 머릿속 쏟아내기, 오늘의 세 가지(받기)

**목표 순간**
- 진입 동기: 머릿속이 꽉 차서 "뭐부터 하지" 하다가 링크나 소개를 보고 처음 들어옴
- 목표 순간: 쏟아낸 게 정리돼 "오늘은 이 세 가지만 하면 돼요"를 받음
- 상태 변화: 머릿속이 엉켜 있음 → 오늘 할 게 세 개로 정해짐

**단계**
| 단계 | 화면 | 기능 | 주 행동 (→ 다음) | 핵심 결정 |
|:--:|------|------|------------------|-----------|
| ① | 첫 화면 | — | [쏟아내기 시작] → ② | 소개 슬라이드 없이 문구 한 줄과 버튼 하나만. 온보딩은 단호하게, 설명은 최소로 |
| ② | 쏟아내기 | 머릿속 쏟아내기 | 적고 [정리해 주세요] → ③ | 큰 입력칸 하나만. 칸을 나누거나 양식을 채우게 하지 않음 — 그것도 스트레스이고 과부하라서 |
| ③ | 오늘 세 가지 | 오늘의 세 가지 | [저장해 둘게요] → ④ | 목표 순간. 세 가지를 크게, 나머지는 접어둠. 항목마다 `⋯`로 바꾸기·나중에. 큰 일의 조각은 보여주지 않음 |
| ④ | 저장 시트 | — | 카카오·구글 로그인 → ⑤ / [나중에 할게요] → 오늘 화면(F2) | 아래에서 올라오는 시트라 세 가지가 뒤에 그대로 보임. 건너뛰면 이 기기에만 저장 |
| ⑤ | 아침 알림 시트 | — | [알려주세요] 또는 [괜찮아요] → 오늘 화면(F2) | 거절해도 다시 묻지 않음 |

**화면**

### ① 첫 화면
```
 ┌──────────────────────┐
   덜어냄

   머릿속에 있는 거,
   순서 없이 쏟아내 주세요.
   정리는 제가 할게요.

   [   쏟아내기 시작   ]
 └──────────────────────┘
```
- **역할:** 무엇을 하는 곳인지 한 줄로 알고, 고민 없이 바로 시작한다.
- **핵심 요소:** 위쪽에 서비스 이름 "덜어냄". 화면 가운데에 큰 문구 두 줄과 작은 문구 한 줄. 아래에 노란 주요 버튼 [쏟아내기 시작] 하나. 소개 슬라이드·기능 설명 없음.
- **문구:** "머릿속에 있는 거, 순서 없이 쏟아내 주세요." / "정리는 제가 할게요."

### ② 쏟아내기
```
 ┌──────────────────────┐
   머릿속에 있는 거,
   순서 없이 쏟아내 주세요.
   ┌──────────────────┐
   │ 주간보고 작성,   │
   │ 운동, 엄마 생신  │
   │ 선물, 결혼식,    │
   │ 병원, 출장 준비… │
   └──────────────────┘
     [  정리해 주세요  ]
 └──────────────────────┘
```
- **역할:** 정리하지 않은 채로 머릿속을 비운다.
- **핵심 요소:** 위에 안내 문구. 화면 대부분을 차지하는 큰 입력칸 하나 — 칸 나누기·분류 선택·마감일 입력 같은 양식 없음. 입력칸 안에 예시가 흐린 글씨로 깔려 있고, 적기 시작하면 사라짐. 아래에 노란 주요 버튼 [정리해 주세요].
- **문구:** "머릿속에 있는 거, 순서 없이 쏟아내 주세요." / 예시: "주간보고 작성, 운동, 엄마 생신 선물, 결혼식, 병원, 출장 준비…"
- **상태:**
  - 빈: 아무것도 안 적음 — 예시만 흐리게 보이고 [정리해 주세요]는 흐리게 꺼둠
  - 로딩: 세 줄 자리가 회색으로 깔리고, 기다리는 동안 문구가 바뀌어 가며 나옴 — "정리하는 중이에요" → "덜어냄이 정리를 도와줘요" … (임시)
  - 오류: 정리 실패 — "정리하지 못했어요. 적은 건 그대로 있어요." (임시) + [다시 정리하기]

### ③ 오늘 세 가지
```
 ┌──────────────────────┐
   오늘은 이 세 가지만
   하면 돼요.

   1  주간보고 작성      업무    ⋯
   2  엄마 생신 선물     개인    ⋯
   3  운동 30분          자기 계발 ⋯

   ▸ 나머지 3개는 잠깐 접어둘게요

   [   저장해 둘게요   ]
 └──────────────────────┘

   ⋯ 를 누르면
   ┌────────────────────┐
   │ 다른 걸로 바꾸기   │
   │ 나중에 할게요      │
   └────────────────────┘
```
- **역할:** 덜어냄이 대신 정한 오늘 할 일을 받는다. "오늘은 이것만 하면 돼"를 처음 느끼는 순간.
- **핵심 요소:**
  - 위에 큰 제목. 그 아래 할 일이 우선순위 순으로 번호와 함께 크게 세 줄. 각 줄 오른쪽에 분류(업무·개인·자기 계발)를 작게, 그 옆에 `⋯`.
  - 보통은 세 개. 오늘이 마감이거나 오늘 정해진 약속에 묶인 일이 셋보다 많으면 그만큼 더 보여주고, 제목은 "오늘은 이것만 하면 돼요."로 바꿈. 셋보다 적으면 있는 만큼만.
  - 큰 일도 조각으로 쪼개 보여주지 않음 — 처음부터 과부하가 올 수 있어서. 쪼개기는 F2에서 항목을 눌러 시작할 때.
  - `⋯`(또는 항목 길게 누르기) → 작은 메뉴: "다른 걸로 바꾸기"(접어둔 할 일 중에서 고름) / "나중에 할게요"(접어둔 목록으로 내리고, 빈자리는 덜어냄이 다음 할 일로 바로 채운 뒤 "○○를 넣어뒀어요"라고 알림). 일정이 바뀌었거나 미뤄도 되는 일일 수 있어서 바꿀 수 있게 함.
  - 그 아래 접기 버튼 "나머지 N개는 잠깐 접어둘게요" — 누르면 펼쳐짐.
  - 맨 아래 노란 주요 버튼 [저장해 둘게요].
- **문구:** "오늘은 이 세 가지만 하면 돼요." / (셋을 넘을 때) "오늘은 이것만 하면 돼요." / "나머지 N개는 잠깐 접어둘게요" / "다른 걸로 바꾸기" (임시) / "나중에 할게요" (임시) / "○○를 넣어뒀어요" (임시)
- **상태:**
  - 빈(할 일을 못 찾음): "오늘은 일정이 없어요! 오늘 완전히 머리를 비워봐요" + 작게 [다시 쏟아내기] (임시) → ②
  - 빈(접어둔 게 없음): 접기 버튼을 숨김
  - 로딩: ② 로딩 참고
  - 오류: ② 오류 참고

### ④ 저장 시트
```
 ┌──────────────────────┐
   (뒤에 오늘 세 가지가 흐리게)
 ├──────────────────────┤
   오늘 세 가지,
   저장해 둘까요?
   [ 카카오로 계속하기 ]
   [ Google로 계속하기 ]
   계속하면 약관과 개인정보 처리에 동의해요.
        나중에 할게요
 └──────────────────────┘
```
- **역할:** 받은 세 가지를 잃지 않게 저장한다. 강요하지 않는다.
- **핵심 요소:** ③ 위로 아래에서 올라오는 시트, 뒤에 세 가지가 그대로 보임. 카카오 로그인 버튼(카카오 로그인 전용 노랑 #fee500), Google 로그인 버튼, 동의 한 줄, 맨 아래 작은 글자 링크 [나중에 할게요].
- **문구:** "오늘 세 가지, 저장해 둘까요?" (임시) / "계속하면 약관과 개인정보 처리에 동의해요." (임시) / "나중에 할게요"
- **상태:**
  - 로딩: 누른 로그인 버튼에 진행 표시
  - 오류: "로그인하지 못했어요. 세 가지는 그대로 있어요." (임시)

### ⑤ 아침 알림 시트
```
 ┌──────────────────────┐
   내일 아침에
   세 가지 알려드릴까요?
   [   알려주세요   ]
        괜찮아요
 └──────────────────────┘
```
- **역할:** 내일 다시 올 계기를 만든다.
- **핵심 요소:** ④와 같은 아래 시트. 노란 주요 버튼 [알려주세요], 그 아래 작은 글자 [괜찮아요]. 누르면 브라우저 알림 권한 창이 뜸.
- **문구:** "내일 아침에 세 가지 알려드릴까요?" (임시) / "알려주세요" (임시) / "괜찮아요" (임시)

**예외**
| 단계 | 상황 | 어떻게 동작하나 |
|:--:|------|----------------|
| ② | 쓰다가 나감 | 쓴 걸 기기에 임시 저장하고, 다시 오면 그대로 보여줌 |
| ②③ | 같은 일을 두 번 적음 | 하나로 합침 |
| ③ | "나중에 할게요"를 눌렀는데 접어둔 게 없음 | 그 자리를 비우고 남은 것만 "오늘은 이것만 하면 돼요."로 보여줌 |
| ③ | 로그인 전에 나감 | 기기에 저장해 두고, 다시 오면 오늘 화면(F2)으로 열림 |
| ④ | 로그인을 취소함 | 시트를 닫고 ③으로 돌아감 |
| ④ | 다른 기기에서 쓰던 계정 | 이번에 쏟아낸 할 일을 기존 할 일에 합침 |
| ⑤ | 브라우저가 알림을 지원하지 않음 (아이폰 Safari 등) | 이 단계를 건너뜀 |
| ⑤ | 알림을 거절함 | 다시 묻지 않음 |

**첫 버전 범위**
- 넣음: 첫 화면, 쏟아내기(글자 입력 한 칸), 자동 분류·우선순위, 오늘 세 가지(오늘 꼭 할 일이 많으면 그 이상)와 나머지 접기, `⋯` 바꾸기·나중에, 저장 시트([나중에 할게요] 포함), 아침 알림 묻기
- 나중에: 음성 입력. 조각 쪼개기는 F2, 캘린더를 보고 우선순위 정하기는 F3, 반복 할 일 알아채기는 F4에서 다룸

**건너뛴 기본값:** 세 가지는 우선순위 순 번호, 분류는 작게 / 셋보다 적으면 있는 만큼만 / 입력은 글자만 / 알림 거절 시 다시 묻지 않음 / 아무것도 안 적으면 [정리해 주세요] 꺼둠

## F2 · 오늘 하나씩 덜기 — "오늘 뭐 하면 되지?"
> 구분: 다시 오기 · 상태: 기획 완료 · 담당 기능: 오늘의 세 가지(접기·펼치기), 한 조각씩 하기, 내일 준비 챙기기(보기), 반복 확인 할 일(섞이기), 일정 모아 보기(보기)

**목표 순간**
- 진입 동기: 아침 알림 "오늘 세 가지 정리해뒀어요."(F1에서 알림을 켰을 때), 또는 "오늘 뭐 하지?" 하고 스스로 떠올려 홈 화면 바로가기로 엶
- 목표 순간: 오늘 세 가지 중 하나를 눌러 한 조각을 덜고 "조금 가벼워졌죠?"를 들음
- 상태 변화: 오늘 뭐부터 할지 막막함 → 하나 해냈다는 감각

**단계**
| 단계 | 화면 | 기능 | 주 행동 (→ 다음) | 핵심 결정 |
|:--:|------|------|------------------|-----------|
| ① | 오늘 화면 | 오늘의 세 가지, 일정 모아 보기(보기), 반복 확인 할 일(섞이기), 내일 준비 챙기기(보기) | 작은 일은 ○ 탭으로 바로 덜기 / 큰 일 이름 탭 → ② | 오늘 세 가지는 남은 할 일과 어제 못 한 일에서 덜어냄이 밤사이 다시 정해 둠(마감 기준). 일정은 위에 작게, 세 가지는 크게. 어제 못 한 일은 한 줄로만 알림 |
| ② | 한 조각 | 한 조각씩 하기 | [덜었어요] → ③ | 큰 일은 3~5조각으로 쪼개되 지금 할 조각 하나만 보여줌. 진행은 점(● ○ ○ ○)으로만 |
| ③ | 한 조각 (덜고 난 뒤) | 한 조각씩 하기 | [다음 조각] → ② / [오늘 화면으로] → ④ | 목표 순간. 팝업 없이 같은 화면에서 취소선 + 끝낸 것 → 다음 조각 → 다독임 순서의 응원 |
| ④ | 오늘 화면 (돌아옴) | 오늘의 세 가지(접기·펼치기) | 다른 할 일 탭 → ② / 앱 닫기 | 끝낸 일은 취소선 뒤 "끝낸 일" 접기로. 빈자리는 채우지 않음. 세 가지를 다 덜면 끝을 알리고 작게 [하나 더] |

**오늘 세 가지를 정하는 순서**
1. 오늘이 마감이거나 오늘 약속에 묶인 일 — 셋보다 많으면 그만큼 더 보여주고 제목은 "오늘은 이것만 하면 돼요." (D-029)
2. 마감이 가까운 일 — 마감은 쏟아낸 글에서 읽고("금요일까지 보고서"), 캘린더를 연결했으면 일정에서도 읽음(F3)
3. 어제 못 한 일 — 오래 미뤄진 일일수록 앞으로
4. 마감이 없는 일 — 업무·개인·자기 계발이 한쪽으로 몰리지 않게 섞음

마감을 모르는 일이 있어도 따로 묻지 않음(D-025 양식 없음).

**화면**

### ① 오늘 화면
```
 ┌──────────────────────┐
   10월 17일 금요일
   ─ 10:00 팀 회의 · 19:00 저녁 약속 ─   (캘린더 연결 시)

   오늘은 이 세 가지만
   하면 돼요.
   ○ 1  주간보고 작성       업무
   ○ 2  엄마 생신 선물      개인
   ○ 3  가계부 정리  반복   개인

   어제 일 하나를 오늘 세 가지에 넣어뒀어요.

   ▸ 나머지 4개는 잠깐 접어둘게요
   ▸ 끝낸 일
                              [＋]
   일정도 같이 볼까요?          (연결 전)
 └──────────────────────┘
```
- **역할:** 다시 열자마자 오늘 할 것을 고민 없이 받는다. 실제로 가장 자주 보는 화면.
- **핵심 요소:**
  - 맨 위 오늘 날짜. 그 아래 캘린더 일정이 시간 순으로 작게 한 줄(가로로 이어짐). 캘린더를 연결하기 전엔 이 줄을 숨김.
  - 큰 제목과 할 일 세 줄(F1 ③과 같은 모양 — 번호, 분류 작게, `⋯`로 바꾸기·나중에). 각 줄 왼쪽에 동그라미 ○. 반복 할 일은 이름 옆에 작게 "반복". 내일 준비 할 일은 이름 아래 작게 근거("내일 출장 있어요").
  - 작은 일: ○를 누르면 그 자리에서 취소선이 그어지고 짧은 응원("하나 덜었어요. 조금 가벼워졌죠?")이 잠깐 뜬 뒤 "끝낸 일"로 내려감.
  - 큰 일(덜어냄이 조각이 필요하다고 본 일): 이름 오른쪽에 작은 화살표 ›. 이름을 누르면 ② 한 조각. 이미 덜어낸 조각이 있으면 점(● ● ○ ○)이 작게 붙음.
  - 어제 못 한 일을 넣었으면 세 가지 아래 한 줄 안내.
  - 접기 두 개: "나머지 N개는 잠깐 접어둘게요", "끝낸 일"(오늘 끝낸 것만).
  - 오른쪽 아래 작은 [＋] — F4 떠오른 거 넣어두기로 이어질 자리.
  - 캘린더 연결 전엔 맨 아래 작은 링크 "일정도 같이 볼까요?" → F3. 로그인 안 했으면 여기서 로그인도 함께 권함(D-023).
  - 노란 주요 버튼 없음 — 이 화면의 주 행동은 할 일을 누르는 것.
- **문구:** "오늘은 이 세 가지만 하면 돼요." / "어제 일 하나를 오늘 세 가지에 넣어뒀어요." / "나머지 N개는 잠깐 접어둘게요" / "끝낸 일" (임시) / "하나 덜었어요. 조금 가벼워졌죠?" (임시) / "일정도 같이 볼까요?" (임시) / 아침 알림: "오늘 세 가지 정리해뒀어요." (임시)
- **상태:**
  - 빈(세 가지를 다 덜었음): "오늘 할 일은 다 덜었어요." + 작은 링크 "하나 더 해볼까요?" (임시) — 누르면 접어둔 것 중 다음 할 일 하나가 올라옴
  - 빈(남은 할 일이 아예 없음): "오늘 할 일은 다 덜었어요." + [쏟아내기] → F1 쏟아내기
  - 로딩: 세 줄 자리가 회색으로 깔림 (F1 ② 로딩과 같은 방식)
  - 오류: "오늘 세 가지를 불러오지 못했어요. 잠시 뒤 다시 가져올게요." (임시) — 기기에 남은 마지막 목록을 보여줌

### ② 한 조각
```
 ┌──────────────────────┐
   ← 주간보고 작성
   ● ○ ○ ○

   지금 할 조각
   이번 주 한 일
   메모 모으기

   [     덜었어요     ]
        나중에 할게요
 └──────────────────────┘
```
- **역할:** 큰 일을 앞에 두고 막히지 않게, 지금 할 조각 하나만 본다.
- **핵심 요소:** 위에 뒤로 가기와 할 일 이름. 그 아래 조각 진행 점(덜어낸 조각은 채운 점, 퍼센트·숫자 없음). 화면 가운데 "지금 할 조각" 작은 제목과 조각 이름을 크게. 다음 조각들은 보여주지 않음. 아래 노란 주요 버튼 [덜었어요], 그 아래 작은 글자 [나중에 할게요]. 처음 누른 할 일이면 이때 3~5조각으로 쪼갬(덜어냄이 정함).
- **문구:** "지금 할 조각" (임시) / "덜었어요" / "나중에 할게요"
- **상태:**
  - 로딩(쪼개는 중): "조각으로 나누는 중이에요" (임시)
  - 오류(쪼개지 못함): 쪼개지 않은 채 할 일 통째로 [덜었어요] + "조각으로 나누지 못했어요. 통째로 해도 괜찮아요." (임시)

### ③ 한 조각 (덜고 난 뒤)
```
 ┌──────────────────────┐
   ← 주간보고 작성
   ● ● ○ ○

   ~~이번 주 한 일 메모 모으기~~
   한 조각 덜었어요.
   다음 조각은 '초안 세 줄
   쓰기'예요.
   조금 가벼워졌죠?
   숨 한 번 고르고 가요.

   [     다음 조각     ]
        오늘 화면으로
 └──────────────────────┘
```
- **역할:** 목표 순간. 하나 해냈다는 감각을 받고, 숨 고른 뒤 이어갈지 정한다.
- **핵심 요소:** ②와 같은 화면에서 바뀜(팝업 없음). 끝낸 조각에 취소선, 점 하나가 채워짐. 그 아래 응원 문구 — 끝낸 것 → 다음 조각 → 다독임 순서. 노란 주요 버튼 [다음 조각], 작은 글자 [오늘 화면으로].
- **문구:** "한 조각 덜었어요." / "다음 조각은 '○○'예요." / "조금 가벼워졌죠? 숨 한 번 고르고 가요."
- **상태:**
  - 마지막 조각을 덜었을 때: "주간보고 작성, 다 덜었어요. 조금 가벼워졌죠?" (임시) + 노란 버튼 [오늘 화면으로]

### ④ 오늘 화면 (돌아옴)
- → F2 ① 참고. 달라지는 점: 방금 끝낸 할 일은 취소선이 그어진 채 "끝낸 일" 접기로 내려가고, 빈자리는 채우지 않음. 조각이 남은 큰 일은 점(● ● ○ ○)이 붙은 채 그 자리에 있음.

**예외**
| 단계 | 상황 | 어떻게 동작하나 |
|:--:|------|----------------|
| ② | [나중에 할게요]를 누름 | 덜어낸 조각은 그대로 두고 오늘 화면으로. 다음에 누르면 남은 조각부터 이어서 |
| ②③ | 하다가 앱을 닫음 | 조각 진행을 기억하고, 다시 열면 오늘 화면으로 열림 |
| ①④ | 잘못 덜었음 | "끝낸 일"에서 다시 눌러 되돌림 |
| ① | 어제 못 한 일이 여러 개 | 숫자로 세지 않음 — "어제 일 몇 개를 다시 넣어뒀어요." (임시) |
| ① | 며칠 만에 옴 | 밀린 날을 세지 않고 오늘 기준으로 세 가지를 다시 정함 |
| ① | 로그인 안 하고 다른 기기에서 엶 | 처음 온 사람처럼 F1 첫 화면 (이 기기에만 저장된다는 건 F1 ④에서 이미 알림) |
| ① | 로그인이 풀림 | 저장 시트(F1 ④)를 다시 띄움 — "다시 이어서 볼까요?" (임시) |
| ① | 날짜가 바뀌는 시점 | 새벽 4시 기준. 늦게 자도 하루가 쪼개지지 않게 |
| 알림 | 오늘 할 일이 없음 | 아침 알림을 보내지 않음 |

**첫 버전 범위**
- 넣음: 아침 알림, 오늘 화면(세 가지·나머지 접기·끝낸 일 접기·어제 일 넣어뒀다는 한 줄), 작은 일은 ○로 바로 덜기, 큰 일은 한 조각 화면(쪼개기·덜었어요 응원·다음 조각·나중에), 다 덜었을 때 "하나 더 해볼까요?", 로그인 유지
- 나중에: 조각 직접 고치기. 오늘 화면의 일정 줄과 내일 준비는 자리만 두고 F3을 만들 때 실제로 채움. 반복 할 일 등록과 [＋]는 F4에서

**건너뛴 기본값:** 아침 알림 문구 "오늘 세 가지 정리해뒀어요." / 캘린더 연결 전엔 일정 줄을 숨기고 맨 아래 "일정도 같이 볼까요?" 링크 / 반복 할 일은 섞되 "반복"만 작게 표시 / 쪼개기는 그 할 일을 처음 누를 때, 조각은 덜어냄이 정하고 첫 버전에선 고칠 수 없음 / 조각 진행은 점으로만, 퍼센트 없음 / 날짜는 새벽 4시에 바뀜 / "끝낸 일"엔 오늘 것만

## F3 · 캘린더 모으기 — "일정도 같이 보고 싶어"
> 구분: 기능 · 상태: 후보 · 담당 기능: 일정 모아 보기(연결), 내일 준비 챙기기(근거)

네이버·구글·커플 달력을 연결해 오늘 화면에 일정을 함께 띄우는 흐름. 아직 그리지 않음.

## F4 · 떠오른 거 넣어두기 — "아 맞다, 그것도 해야지"
> 구분: 기능 · 상태: 후보 · 담당 기능: 머릿속 쏟아내기(추가), 반복 확인 할 일(등록)

하던 중에 떠오른 걸 재빨리 넣어두고 하던 조각으로 돌아오는 흐름. 아직 그리지 않음.
