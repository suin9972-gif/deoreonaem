# 01 · F1 처음 쏟아내기

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: UI 구현 · 관련 플로우: F1 · 조각 4개
> 정해둔 것: ../SETUP.md

- [ ] **1. 프로젝트 준비 + 첫 화면 → 쏟아내기** (F1 ①②)
  - 확인: 첫 화면에 "머릿속에 있는 거, 순서 없이 쏟아내 주세요."와 "정리는 제가 할게요."가 보인다
  - 확인: [쏟아내기 시작] → 큰 입력칸에 "주간보고 작성, 운동, 엄마 생신 선물, 결혼식, 병원, 출장 준비…"가 흐리게 보이고, 아무것도 안 적으면 [정리해 주세요]가 꺼져 있다
  - 확인: 쓰다가 새로고침해도 쓴 글이 그대로 있다
- [ ] **2. 정리하기 → 오늘 세 가지** (F1 ②③)
  - 확인: 여러 일을 적고 [정리해 주세요] → "오늘은 이 세 가지만 하면 돼요." 아래 번호 붙은 세 줄과 분류(업무·개인·자기 계발)가 보인다
  - 확인: "나머지 N개는 잠깐 접어둘게요"를 누르면 나머지가 펼쳐지고, 나머지가 없으면 이 버튼이 보이지 않는다
  - 확인: 같은 일을 두 번 적으면 한 줄로 합쳐 보인다
  - 확인: "오늘"이 들어간 일을 넷 이상 적으면 그만큼 다 보이고 제목이 "오늘은 이것만 하면 돼요."로 바뀐다
- [ ] **3. `⋯`로 바꾸기·나중에** (F1 ③)
  - 확인: 항목의 `⋯` → "다른 걸로 바꾸기" → 접어둔 일 중 하나를 고르면 그 자리가 바뀐다
  - 확인: "나중에 할게요" → 그 일은 접어둔 목록으로 내려가고, 빈자리에 다음 일이 들어오며 "○○를 넣어뒀어요"가 보인다
  - 확인: 접어둔 게 없을 때 "나중에 할게요"를 누르면 남은 것만 "오늘은 이것만 하면 돼요."로 보인다
- [ ] **4. 저장 시트 + 아침 알림 시트** (F1 ④⑤)
  - 확인: [저장해 둘게요] → 아래에서 시트가 올라오고, 뒤에 세 가지가 흐리게 보인다
  - 확인: [카카오로 계속하기]를 누르면 바로 "내일 아침에 세 가지 알려드릴까요?" 시트로 넘어간다
  - 확인: [나중에 할게요]를 누르거나 시트 바깥을 누르면 시트가 닫히고 세 가지가 그대로 있다
  - 확인: [괜찮아요] 뒤에 새로고침하면 첫 화면이 아니라 세 가지가 열리고, 알림을 다시 묻지 않는다
