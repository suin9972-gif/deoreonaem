# 03 · F2 오늘 하나씩 덜기

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: UI 구현 · 관련 플로우: F2 · 조각 6개
> 정해둔 것: ../SETUP.md

- [ ] **1. 오늘 화면 — F1 다음, 그리고 다시 열 때** (F2 ① · F1 저장 시트·아침 알림 시트 뒤)
  - 확인: F1에서 [저장해 둘게요] → [나중에 할게요]를 누르면 맨 위에 오늘 날짜가 있는 오늘 화면이 나오고, 할 일마다 왼쪽에 ○가 있다
  - 확인: 오늘 화면에서 새로고침해도 오늘 화면이 다시 열린다
  - 확인: 노란 주요 버튼이 없고, 맨 아래에 "일정도 같이 볼까요?"가 작게 보인다
- [ ] **2. ○로 바로 덜기와 끝낸 일** (F2 ①④)
  - 확인: 작은 일의 ○를 누르면 취소선과 "하나 덜었어요. 조금 가벼워졌죠?"가 잠깐 보이고, 그 일은 "끝낸 일" 접기로 내려간다
  - 확인: 덜고 난 빈자리는 다른 일로 채워지지 않는다
  - 확인: "끝낸 일"을 펼쳐 그 일을 다시 누르면 오늘 세 가지로 되돌아온다
- [ ] **3. 다 덜었을 때** (F2 ① 빈 상태)
  - 확인: 세 가지를 다 덜면 "오늘 할 일은 다 덜었어요."와 "하나 더 해볼까요?"가 보이고, 누르면 접어둔 것 중 하나가 올라온다
  - 확인: 남은 할 일이 아예 없으면 "오늘 할 일은 다 덜었어요."와 [쏟아내기]가 보이고, 누르면 쏟아내기 화면이 나온다
- [ ] **4. 한 조각 화면** (F2 ②③)
  - 확인: 큰 일(이름 옆 ›)을 누르면 "지금 할 조각"과 조각 하나, 진행 점(● ○ ○ ○ 처럼)이 보이고, 다음 조각들은 보이지 않는다
  - 확인: [덜었어요]를 누르면 팝업 없이 같은 화면에서 끝낸 조각에 취소선이 그어지고 "한 조각 덜었어요." / "다음 조각은 '○○'예요." / "조금 가벼워졌죠? 숨 한 번 고르고 가요."가 보이며 점 하나가 채워진다
  - 확인: 마지막 조각을 덜면 "○○, 다 덜었어요. 조금 가벼워졌죠?"와 [오늘 화면으로]가 보이고, 오늘 화면에서 그 일은 "끝낸 일"에 가 있다
- [ ] **5. 이어서 하기와 나중에** (F2 ②④ 예외)
  - 확인: 한 조각에서 [나중에 할게요] → 오늘 화면에 그 일이 채운 점(● ○ ○ ○)을 단 채 남아 있고, 다시 누르면 남은 조각부터 나온다
  - 확인: 조각을 하다가 새로고침하면 오늘 화면이 열리고, 진행 점은 그대로다
- [ ] **6. 하루가 지나면** (F2 ① 정하는 순서·예외)
  - 확인: [하루 넘기기]를 누르면 날짜가 바뀌고, 못 끝낸 일이 다시 세 가지에 들어가며 "어제 일 하나를 오늘 세 가지에 넣어뒀어요."가 보인다 (여러 개면 "어제 일 몇 개를 다시 넣어뒀어요.")
  - 확인: 하루를 넘기면 "끝낸 일" 접기에는 어제 끝낸 일이 보이지 않는다
