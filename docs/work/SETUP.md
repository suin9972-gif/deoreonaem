# Setup — 덜어냄

> Vibe Studio · build-spec · 모든 작업 묶음이 같이 쓰는 것
> 작성일: 2026-10-16 · 최종 수정일: 2026-10-16
> 기반: docs/PRODUCT.md, docs/FLOWS.md, docs/DESIGN.md, docs/DECISIONS.md

- **스택:** 실제 기능 — Next.js (App Router) + TypeScript + Tailwind CSS · 아이콘 Lucide(`lucide-react`) · 글꼴 Pretendard
  - 이유: 쏟아낸 걸 나누고 우선순위를 매기는 AI 정리가 서비스의 핵심이라, 나중에 AI 키를 서버에 숨겨야 함
- **데이터:** 사용자가 쏟아낸 글과 정리 결과를 브라우저에 저장(새로고침해도 남게). 미리 넣어둘 가짜 데이터는 없음 — 화면은 사용자가 적은 걸로 채움. 진짜 저장소는 나중에
- **흉내만 낼 것:**
  - AI 정리 — 쉼표·줄바꿈으로 나누고, 같은 일은 합치고, 낱말로 업무·개인·자기 계발을 나누고, "오늘"이 들어간 일을 맨 앞에 두는 규칙으로 대신함. 잠깐 기다리는 시간을 넣어 로딩이 보이게
  - 카카오·Google 로그인 — 누르면 바로 로그인된 것으로 처리
  - 아침 알림 — 브라우저 알림 권한만 실제로 묻고, 아침에 보내는 알림은 없음
- **이번엔 안 함:** 음성 입력, 진짜 AI 정리, 진짜 카카오·Google 로그인, 실제 아침 알림 발송, 다른 기기에서 쓰던 계정과 할 일 합치기, 진짜 저장소, F2~F4(조각 쪼개기·캘린더 모으기·떠오른 거 넣어두기), 설정 화면·로그아웃, 단기·중기·장기 계획
