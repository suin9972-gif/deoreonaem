# 02 · F1 처음 쏟아내기 — AI 정리를 진짜로

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: 기능 구현 (AI 정리만 — 로그인·저장·알림은 흉내 그대로) · 관련 플로우: F1 · 조각 3개
> 정해둔 것: ../SETUP.md

- [ ] **1. 서버에서 AI로 정리하기** (F1 ②③)
  - 확인: "치과 스케일링, 분기 실적 정리, 기타 연습"을 적고 [정리해 주세요] → 각각 개인 · 업무 · 자기 계발로 나뉘어 보인다 (지금의 낱말 규칙으로는 못 맞히는 말들)
  - 확인: "운동, 넷플릭스 보기, 내일 마감 제안서"를 적으면 "내일 마감 제안서"가 1번에 온다
  - 확인: 브라우저 개발자 도구에서 페이지 코드와 오가는 요청을 봐도 API 키가 보이지 않는다
- [ ] **2. 뜻으로 합치고, 오늘 꼭 할 일 알아채기** (F1 ②③)
  - 확인: "엄마 생신 선물, 엄마 생일 선물 사기"처럼 다르게 적은 같은 일이 한 줄로 합쳐진다
  - 확인: "오늘"이라는 말 없이 "오후 3시 치과, 저녁 7시 회식, 6시까지 보고서 제출, 퇴근 전 결재 올리기, 운동"을 적으면 앞의 넷이 다 보이고 제목이 "오늘은 이것만 하면 돼요."로 바뀐다
  - 확인: "ㅋㅋㅋ 배고프다"처럼 할 일이 없는 글이면 "오늘은 일정이 없어요! 오늘 완전히 머리를 비워봐요"가 보인다
- [ ] **3. 정리하지 못했을 때** (F1 ②)
  - 확인: 정리에 실패하면(인터넷을 끊거나 키를 빼고 [정리해 주세요]) "정리하지 못했어요. 적은 건 그대로 있어요."와 [다시 정리하기]가 보이고, 쓴 글은 그대로 남아 있다
  - 확인: 다시 연결한 뒤 [다시 정리하기]를 누르면 오늘 세 가지가 나온다
