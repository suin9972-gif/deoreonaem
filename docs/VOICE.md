## 확정 정보
- **서비스 이름:** 덜어냄
- **한 줄 무드:** 머릿속 짐을 조용히 나눠 들고, 오늘은 이것만 하면 된다고 건네는 차분한 단짝

## 1. Voice Summary
짐을 나눠 드는 차분한 단짝처럼 말해요. 복잡한 건 말없이 대신 정리해 두고, 할 일은 분명하게 건네며, 한 조각 끝낼 때마다 작게 알아봐 줘요.

## 2. Core Personality Traits

**차분한**
- We are: 서두르게 만들지 않아요. 놓친 일도 담담하게 알려주고 다시 자리를 잡아줘요.
- We are not: 무기력하거나 늘어지지 않아요. 할 일은 여전히 앞으로 나아가요.
- This sounds like: "어제 일 하나를 오늘 세 가지에 넣어뒀어요."
- This does NOT sound like: "🔥 연속 완료 기록이 끊겼어요! 오늘 다시 시작해볼까요?"

**단호한 (대신 정해줌)**
- We are: 고민할 거리를 남기지 않고 "이거 하면 돼요"라고 분명히 정해줘요.
- We are not: 명령하거나 다그치지 않아요. 결정을 사용자에게 다시 떠넘기지도 않아요.
- This sounds like: "오늘은 이 세 가지만 하면 돼요."
- This does NOT sound like: "지금 당장 시작하세요."

**다정한**
- We are: 해낸 걸 바로 알아봐 주고, 못 끝낸 날에도 "이만큼 했네"를 먼저 보여줘요.
- We are not: 호들갑 떨거나, 위로만 하는 힐링 과잉이 아니에요.
- This sounds like: "한 조각 덜었어요. 시작이 제일 어려웠어요."
- This does NOT sound like: "괜찮아요 🌷 오늘의 당신도 충분히 소중해요 💕"

**간결한**
- We are: 한 문장에 한 가지만 말해요. 머릿속이 가득 찬 사람도 한눈에 읽어요.
- We are not: 차갑거나 사무적이지 않아요. 짧아도 말투는 따뜻해요.
- This sounds like: "첫 조각 끝. 다음은 '참고문헌 3개 훑기'예요."
- This does NOT sound like: "오늘 목표 미달성. 분발하세요."

## 4. Vocabulary Guide

**USE**
- **덜었어요** — 할 일·조각을 끝냈을 때. 브랜드 이름과 이어지는 대표 표현
- **~만 하면 돼요** — 오늘 세 가지를 건넬 때. 결정을 대신 해줬다는 안심
- **오늘 세 가지** — 메인 화면의 고정 표현. "목표"·"과제" 대신
- **한 조각** — 큰 일을 쪼갠 단위. "단계"·"서브태스크" 대신
- **다음 조각은** — 끝낸 직후 다음 할 일을 이어줄 때
- **넣어뒀어요 / 챙겨뒀어요** — 놓친 일·내일 준비를 대신 배치했을 때
- **이만큼 했어요** — 못 끝낸 날, 한 것을 먼저 보여줄 때
- **잠깐 접어둘게요** — 나머지 할 일을 숨길 때. 없앤 게 아니라 접어둔 것
- **쏟아내 주세요** — 입력을 받을 때. 정리 안 해도 된다는 신호
- **조금 가벼워졌죠?** — 성공 피드백의 마무리. 덜어낸 감각과 함께 마음을 가라앉힘
- **숨 한 번 고르고 가요** — 다음 조각으로 넘어가기 전, 서두르지 않게
- **내일 ○○ 있어요** — 내일 일정을 근거로 오늘 준비를 알려줄 때
- **괜찮아요, 다시** — 놓친 일을 다시 배치할 때 짧게. 위로는 한 마디까지만

**AVOID**
- **달성률 / %** — 결과를 재촉하는 생산성 코치 톤
- **미완료 / 미달성** — 못 한 걸 세는 말
- **연속 기록 / 스트릭** — 끊겼다는 압박이 자책으로 이어짐
- **또 미루셨네요** — 죄책감을 건드림
- **지금 당장 / 꼭 / 반드시** — 단호함이 명령이 됨
- **분발하세요 / 화이팅** — 다그치거나 공허한 응원
- **대박 / 최고예요!!!** — 호들갑, 다정함 과잉
- **당신은 소중해요 / 쉬어도 돼요** — 힐링 과잉, 할 일에서 멀어짐
- **확인하지 않은 ~가 있어요!** — "뭐 놓친 거 없나" 불안을 키움
- **직접 계획을 세워 보세요** — 결정을 사용자에게 다시 떠넘김
- **생산성 / 효율 / 최적화** — 덜어냄이 아닌 더하기의 언어
- **태스크 / 데드라인 / 백로그** — 업무 용어로 무겁게 느껴짐

## 5. Tone Adaptation Rules

| 맥락 | 톤 조절 | 예시 문구 |
|------|---------|-----------|
| 온보딩 / 첫 화면 | 단호함을 올려 할 일을 바로 보여줘요. 설명은 최소 | "머릿속에 있는 거, 순서 없이 쏟아내 주세요. 정리는 덜어냄이 할게요." |
| 빈 상태(empty state) | 차분함을 올려요. 비어 있는 게 좋은 상태라는 느낌 | "오늘 할 일은 다 덜었어요." |
| 성공/완료 피드백 | 다정함을 올려요. ① 끝낸 것 ② 다음 조각 ③ 가벼워졌다는 다독임 순서로, 마음을 가라앉혀 줘요 | "한 조각 덜었어요. 다음 조각은 '참고문헌 3개 훑기'예요. 조금 가벼워졌죠? 숨 한 번 고르고 가요." |
| 에러/안내 | 단호함을 낮추고 차분함을 올려요. 무엇을 하면 되는지만 | "캘린더를 불러오지 못했어요. 잠시 뒤 다시 가져올게요." |
| 놓친 일 다시 넣기 | 놓친 사실은 알리되 숫자로 세지 않고, 이미 다시 넣었다고 말해요 | "어제 일 하나를 오늘 세 가지에 넣어뒀어요." |
| 푸시 알림 | 가장 짧고 조용하게. 꼭 필요할 때만 | "내일 출장 있어요. 오늘 저녁 짐 싸기를 챙겨뒀어요." |
| 랜딩/소개 페이지 | 차분함을 유지하되 가치를 분명하게 | "흩어진 일정과 머릿속을 한곳에. 오늘은 이것만 하면 돼요." |

규칙: 차분함·단호함·다정함·간결함 네 성격은 어디서나 유지하고, 맥락에 따라 비율만 바꿔요. 성공 피드백에서는 다정함을, 첫 화면에서는 단호함을, 에러와 놓친 일 안내에서는 차분함을 키워요. 어느 맥락에서도 재촉·달성률·자책은 등장하지 않아요.

## 6. Style Rules
- 존댓말/반말: 부드러운 해요체 ("~해요", "~했어요")
- 문장 길이: 한 문장에 한 가지만. 한 문구는 최대 두 문장
- 이모지: 기본은 쓰지 않아요. 써도 성공 피드백에서 한 문구에 최대 1개
- 느낌표: 한 문구에 최대 1개, 다그치는 문장에는 쓰지 않아요
- 숫자: 남은 것·해낸 것을 알려줄 때만 쓰고, 못 한 것을 셀 때는 쓰지 않아요
- 주어: "덜어냄이 ~할게요"처럼 서비스가 짐을 드는 주체로 말해요
- 외래어: 업무·생산성 영어 용어 대신 쉬운 한국어 ("태스크" → "할 일", "서브태스크" → "조각")

## 7. Do's and Don'ts

**Do:**
- 할 일은 "~만 하면 돼요"처럼 분명하게 정해서 건네요
- 놓친 일은 담담하게 알리고, 이미 다시 넣어뒀다고 함께 말해요
- 한 조각을 끝내면 끝낸 것 → 다음 조각 → "조금 가벼워졌죠?" 순서로 말해요. 마지막엔 숨 고를 틈을 줘요
- 못 끝낸 날에는 못 한 것보다 한 것을 먼저 보여줘요
- 한 화면, 한 문구에 메시지는 하나만 담아요
- 내일 일정처럼 근거가 있을 때 그 근거를 짧게 말해줘요

**Don't:**
- 달성률·퍼센트·연속 기록으로 결과를 재촉하지 않아요
- "지금 당장", "분발하세요"처럼 명령하거나 다그치지 않아요
- 이모지와 느낌표를 겹쳐 호들갑 떨지 않아요
- "당신은 소중해요"처럼 위로만 하는 힐링 과잉 문구를 쓰지 않아요
- 못 한 일을 숫자로 세거나 "또 미루셨네요"처럼 자책을 건드리지 않아요
- "직접 계획을 세워 보세요"처럼 결정을 사용자에게 다시 떠넘기지 않아요
- "확인하지 않은 일정이 있어요!"처럼 불안을 키우는 경고를 쓰지 않아요
